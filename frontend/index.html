FAQ

Questions

Does Truemailer prove that a mailbox exists?

No. DNS/MX checks establish domain/mail-server capability, not whether a specific inbox exists. The API deliberately reports these as separate signals.

What makes an address disposable?

Known disposable domains, temporary-domain patterns and an external disposable signal can contribute to the verdict.

What does the trust score mean?

It is a rule-based signal from the checks currently available. It is not a guarantee that a person or mailbox is trustworthy.
