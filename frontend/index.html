FAQ

Clear about what verification can prove.

Does Truemailer prove a mailbox exists?

No. DNS and MX checks establish domain/mail-server capability, not inbox ownership or guaranteed deliverability.

What does the trust score mean?

It is a rule-based signal derived from the checks currently available. It is not a guarantee that a person, mailbox or domain is trustworthy.

Can I use the API directly?

Yes. The production API remains on Render and exposes the verification endpoint as JSON.
